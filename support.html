Support

Safety first: only enter or review information when safely parked or otherwise able to use your device safely and legally.

Getting started

Choose a start time, work type, and optional starting odometer, then tap Start shift. Add earnings and expenses while parked or at the end of the shift. Enter an ending odometer and end time to save the summary.

Installing on iPhone

Open the site in Safari while online, tap Share, choose Add to Home Screen, enable Open as Web App if shown, and tap Add. Open it once from the Home Screen so all offline files are cached.

Why does a statistic say “Not available”?

Per-mile statistics need both odometer readings and a positive distance. Hourly statistics need a valid start and end time. The app shows Not available rather than guessing.

Backups and moving to a new phone

Use Export backup in Settings and save the JSON file somewhere safe. On the new device, use Import backup to restore settings, completed shifts, and any active shift.

Where are my records?

Your records are stored in this browser on this device. Clearing site data or deleting the installed web app may remove them, so export a backup first.
